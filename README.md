# GT3-Active-Aero-Workspace
Source code, MATLAB optimization scripts, Simulink-generated and Arduino microcontroller code for portfolio project.

The uploaded .zip file contains all code, optimization and data analysis scripts.

The "Arduino Control" folder contains the Simulink stateflow logic and its generated C code.
It also includes the Arduino C++ code that is uploaded to the microcontroller.
Finally, the folder contains two Python streamers, one which uses previously recorded lap data in a .csv file and the other which uses the live AC telemetry.

The "Optimization & Data Analysis" folder contains all MATLAB scripts that perform the optimizations and figure generations.
